# Fonts

- **Compagnon** Light and Roman, by Juliette Duhé and Léa Pradine, Velvetyne Type Foundry (2018). SIL Open Font License 1.1, embedded in each file; see https://openfontlicense.org.
- **Inter** loads from Google Fonts (SIL Open Font License 1.1).

Product Starter's own fonts, Labil Grotesk and GT Alpina Typewriter, are web-licensed to More Yum and are deliberately **not** in this public repository. `tokens.css` still declares them, but nothing uses them: Folio sets `--font-sans` to Inter and `--font-mono` to Compagnon, the kit's named fallbacks.
